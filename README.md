# WhisperGO for macOS

This repository hosts signed app downloads and the Sparkle update feed for WhisperGO. Source development is maintained separately.

Download the ZIP from [the latest release](https://github.com/Promostrat/WhisperGO-Releases/releases/latest), extract it, and move **WhisperGO.app** to **Applications**. Launch it and enter your own transcription API keys in Settings. Subsequent Mac updates are delivered through Sparkle.

The app requires macOS 14 or later and supports Apple silicon and Intel Macs. Downloads do not contain user API keys, transcripts, recordings, or local model downloads.

The stable signed update feed is:

`https://github.com/Promostrat/WhisperGO-Releases/releases/latest/download/appcast.xml`

WhisperGO is an early prototype. Signatures, notarization and update delivery do not imply that every dictation or sync feature has been validated on every device.
